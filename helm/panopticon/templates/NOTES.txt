Panopticon has been deployed as a DaemonSet.

1. Check the rollout status:

    kubectl rollout status daemonset/{{ include "panopticon.fullname" . }} -n {{ .Release.Namespace }}

2. View agent logs on a specific node:

    kubectl logs -n {{ .Release.Namespace }} -l app.kubernetes.io/name={{ include "panopticon.name" . }} --follow

3. Verify health probes:

    kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/name={{ include "panopticon.name" . }} -o wide

4. Access Prometheus metrics:

    {{ include "panopticon.fullname" . }}-metrics.{{ .Release.Namespace }}.svc:{{ .Values.metrics.port }}/metrics

    The agent binds {{ .Values.metrics.bindAddress }}:{{ .Values.metrics.port }} on each node (hostNetwork).
    /metrics and /debug/state are unauthenticated: keep the port off untrusted networks.

5. Panopticon is EXPERIMENTAL. Exported events and the PII audit log are
   sensitive data{{ if .Values.export.hostPath }} (written under {{ .Values.export.hostPath }} on each node){{ end }}.
